Produits agricoles
Légumes : pommes de terre, oignons, tomates, carottes, poivrons, laitue, concombres, courgettes.
Fruits : oranges, pommes, bananes, raisins, fraises, citrons, grenades, figues.
Produits laitiers : lait, lait fermenté, fromage, beurre, yaourt.
Produits avicoles : œufs, poulet, œufs fermiers.
Viandes : bœuf, agneau, chèvre, poulet.
Produits de la ruche : miel, cire d’abeille, pollen, propolis.
Céréales et aliments pour animaux : blé, orge, maïs, luzerne, foin, aliments pour bétail.
Produits d’olivier : huile d’olive, olives vertes, olives noires.
Semences et plants : graines de légumes, graines de céréales, plants d’olivier, plants fruitiers.
Produits agricoles locaux : huile d’argan, amandes, noix, dattes, raisins secs, plantes aromatiques.
